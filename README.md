# 🎥 YouTube Chatbot 🤖

An AI-powered YouTube Chatbot built using Python, LangChain, and Large Language Models (LLMs). It allows users to chat with YouTube videos, generate summaries, ask questions, and get instant answers based on video transcripts.

## 🚀 Features

- 💬 Chat with YouTube videos.
- 📝 Generate video summaries.
- ❓ Ask questions about video content.
- 📄 Extract YouTube video transcripts.
- 🧠 Get AI-powered context-aware answers.
- ⚡ Interactive chatbot interface.

## 🛠️ Tech Stack

- Python
- LangChain
- LLMs (Large Language Models)
- YouTube Transcript API
- Streamlit
- Prompt Engineering

## 📦 Installation

**1. Clone the repository**

```bash
git clone https://github.com/Som2005/youtube-chat-bot.git
```

**2. Navigate to the project directory**

```bash
cd youtube-chat-bot
```

**3. Install dependencies**

```bash
pip install -r requirements.txt
```

**4. Run the application**

```bash
streamlit run app.py
```

## 🎯 How It Works

1. Enter a YouTube video URL.
2. Extract the video's transcript.
3. Process the transcript using LangChain.
4. Ask questions about the video.
5. Get AI-generated answers instantly.

## 💡 Use Cases

- Learning from educational videos.
- Summarizing long YouTube videos.
- Extracting important information.
- Understanding video content quickly.
